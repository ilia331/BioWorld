# tests/

Всички тестове (стъпки 5 и 6), без инсталиране — нужен е само Node.js:

```bash
node --test tests/*.test.cjs
```

| Файл | Какво проверява |
| --- | --- |
| `actionRules.test.cjs` | Недостиг на вода, максимални стойности, ограничения за добавяне на животни, бутон „Следващ ход“ (стъпка 5) |
| `simulation.test.cjs` | Алгоритъма за един ход: 3 ръчни примера, гранични случаи, 10 хода, прогноза, условия за успех, съвпадение със `seed.sql` (стъпка 6) |

Описание, формули и ръчните сметки: [docs/TESTS.md](../docs/TESTS.md).
